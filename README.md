# FrameGrab

ปุ่มลอยจับเฟรมจากวิดีโอ ใช้ได้เหนือทุกแอปบน Android (TikTok, Instagram, Facebook ฯลฯ)

- 📸 จับภาพทีละภาพ / ⏺ อัดต่อเนื่องทุก 0.25 วินาที
- ดูภาพแบบสตอรี่ ถ่างนิ้วซูม ปัดเปลี่ยนภาพ
- บันทึกลงแกลเลอรี (Pictures/FrameGrab)

ต้องใช้ Android 10 ขึ้นไป

## สร้างไฟล์ติดตั้ง
อัปโหลดโปรเจกต์นี้ขึ้น GitHub แล้ว GitHub Actions จะสร้าง `FrameGrab.apk` ให้เองที่หน้า **Releases**
